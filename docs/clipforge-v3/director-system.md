# Director System

Flow:

Product Brief -> Product Truth -> Reference Asset Audit -> Reference Role Map -> Mode Router -> Fidelity Allocation -> Shot Contract Planner -> Prompt Compiler -> Preflight -> Generation -> Continuity Ledger -> Review -> Retake -> Final Assembly.

Key rules:

- Product Truth must be confirmed before Director Plan.
- Real product image is the identity source.
- One asset has one primary role.
- One shot has one primary visible action.
- One shot has one primary camera movement.
- Product identity, mechanical relation, and working surface override style.
- Dense text, prices, QR codes, and CTA are post-production items.
- If mechanical truth cannot be guaranteed, recommend real shooting instead of infinite rerolls.
