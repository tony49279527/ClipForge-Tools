# Operator Guide

The V3 console is designed for Chinese operators and keeps all core actions visible in the browser.

Visible work areas:

- Left rail: project navigation, budget, risk count.
- Center: workflow stepper, Product Truth, assets, Director Plan, Shot Board, Prompt Inspector, Take Review Studio, Final Assembly.
- Right rail: Product Truth summary, identity assets, blocking errors, cost center, Continuity Ledger, recent operations.

Never start Production without checking:

- Product Truth confirmed.
- Shot Contract confirmed.
- Prompt locked and preflight passed.
- Required references are accessible and user-approved.
- Estimated cost and budget remaining.
- Continuity dependency status.

If a blocking error appears, follow the next-step text shown in the console before retrying.
